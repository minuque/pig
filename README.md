> 遵循 Pi 设计哲学，不额外内置工具，完全通过 Extension API 扩展的交互优秀、高性能 **Pi Agent GUI**。

## 快速开始

```bash
pnpm install        # 安装依赖
pnpm dev            # 启动 Gateway + Web
pnpm dev:desktop    # Electron 桌面开发
```
