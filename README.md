# pig

**[English](README.en.md)** · 简体中文

> local-first、交互优秀、高性能的 **Pi GUI**——Web 与 Desktop 双端，负责呈现与控制 Pi Session，不重新实现 Agent Runtime。

## 快速开始

```bash
pnpm install        # 安装依赖
pnpm dev            # 启动 Gateway + Web
pnpm dev:desktop    # Electron 桌面开发
```
