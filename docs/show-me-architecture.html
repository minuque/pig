本机通行证

HTTP + WebSocket 前置
01 CLI / Desktop分发一次性 tokenCLI 把 launch token 拼进打印的地址，并把同一个交给 Vite；桌面壳对 127.0.0.1 的 http / ws 请求统一补 Authorization
02 BrowserGET /?token=… 换 cookie校验通过后 303 跳回干净地址，写 HttpOnly SameSite=Strict cookie（30 天），签名密钥落在 ~/.pig
03 页面后续请求带凭据同源页面用 cookie；开发态 Vite 代理与桌面壳代理补 Bearer，页面本身不保存 token
04 Gateway校验来源与通行证非回环 host、跨站或 origin 不是本机一律 403，缺通行证 401；静态页、平台 API 和 WebSocket 升级都走这道门

创建或打开会话

平台 HTTP + Pi 协议
01 Router / Welcome得到 sessionId 或 cwd路由打开已有会话，欢迎页创建新会话
02 useSessionHistoryGET platform/transcript先要最近三轮，不阻塞连接
03 useSessionLifecycleopen / create替换串行，快速切换只保留最后目标
04 RemoteSession向 PiClient 发命令官方实例持有会话 lease
05 PiHostService打开或创建 AgentSession通过 SessionManager 找到 JSONL
06 PiHostSession生成 SessionSnapshot只带元数据，正文另走 HTTP
07 Vue projection渲染 Workbench历史窗口与 live progress 按 id 合并

Prompt 与流式 Transcript

WebSocket 双向
01 Composersend → submitTextuseSessionLifecycle 先放 optimistic user item，清空草稿
02 RemoteSessionsubmit(text)PiClient 编码协议命令
03 PiHostSessionexclusive prompt非 idle 或并发操作直接拒绝
04 AgentSession执行 turn 与 tools产生 message_* 和 tool_execution_* 事件
05 Projection事件 → progress同一条消息的连续 delta 只发最后一版；tool 占位与完成条目按 toolCallId 合并
06 message_end微任务后发 snapshot等 Pi 写盘，再用权威快照收敛流式状态
07 TranscriptView合并并渲染RemoteSessionState 覆盖 optimistic item
