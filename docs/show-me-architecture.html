Pi 协议平台 HTTP响应式状态磁盘

启动与授权

HTTP → WebSocket
01 Desktop / CLI生成 secretGateway 只监听 127.0.0.1
02 启动链接#bootstrap=secret片段不发给普通 HTTP 服务
03 StartupPOST /bootstrap用 secret 兑换 credential
04 Browser保存 credential写 localStorage 并清 URL hash
05 PiClient连接 /api/v1/picredential 经查询参数进入 WS upgrade
06 PiServer返回 ServerSnapshotsessions、models、连接状态进入 Vue

创建或打开会话

Pi 协议 + Vue route
01 Router / Welcome得到 sessionId 或 cwd路由打开已有会话，欢迎页创建新会话
02 useRemoteSessionsopen / create替换串行，快速切换只保留最后目标
03 RemoteSession向 PiClient 发命令官方实例持有会话 lease
04 PiHostService打开或创建 AgentSession通过 SessionManager 找到 JSONL
05 PiHostSession生成 SessionSnapshotTranscript 只取当前分支最近 40 条
06 Vue projection渲染 Workbenchsnapshot、phase、transcript 变成 computed

Prompt 与流式 Transcript

WebSocket 双向
01 ChatInputsubmitText先放 optimistic user item，清空草稿
02 RemoteSessionsubmit(text)PiClient 编码协议命令
03 PiHostSessionexclusive prompt非 idle 或并发操作直接拒绝
04 AgentSession执行 turn 与 tools产生 message_* 和 tool_execution_* 事件
05 Projection事件 → progress流式 assistant 与 tool 占位增量发送
06 message_end微任务后发 snapshot等 Pi 写盘，再用权威快照收敛流式状态
07 TranscriptView合并并渲染RemoteSessionState 覆盖 optimistic item

加载更早 Transcript

平台 HTTP → 磁盘
01 TranscriptView点击加载更早取当前窗口第一条 id 作为 before
02 platformRequestGET /transcriptBearer credential + sessionId + before
03 PiHostService打开 SessionManager直接读磁盘当前分支，不占 AgentSession lease
04 Projection返回前一页 40 条同时给出 hasMore
05 useRemoteSessions合并 prefix + latest按 id 去重，保留实时窗口

目录与会话文件操作

平台 HTTP
01 SessionNav选择 / 改名 / 删除导航模块发平台请求
02 Gateway auth校验 Bearer凭证失效统一返回 UNAUTHENTICATED
03 Platform port选目录或操作文件Electron dialog 或手工路径；SessionManager 改 JSONL
04 PiClientrefreshSessions用官方 list 结果覆盖 ServerSnapshot.sessions
05 Nav computed重新分组和渲染本地 projectScope 只筛选，不改会话 cwd
