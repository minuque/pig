# 基础件尺寸档：常规件三档，菜单两档

- 状态：已采纳
- 代码：`apps/web/src/types/ui-type.ts`（`Size`、`MenuSize`）

## 背景

尺寸档决定控件高与内边距的组合，控制高的档位见 `tokens.css` 的 `--control-*`。档位越多，每个基础件要维护的组合越多；而且没有对应控制高的宽松档在大体量菜单里没有落点，菜单行高由控件档与行距给。

## 决定

`Size` 对外只有 `s` / `m` / `l` 三档，不另开第 4 档。`MenuSize` 只要两档：`s` 紧凑、`m` 默认，不做 `l`。

## 后果

新增基础件只能复用这几档；觉得尺寸不够时先查 `--control-*` 是否缺档，不要在类型上加第 4 档。给菜单传 `l` 会类型报错。
