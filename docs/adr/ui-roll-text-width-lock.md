# RollText 换字时锁宽，流式增量原地更新

- 状态：已采纳
- 代码：`apps/web/src/components/ui/roll-text/RollText.vue`（`watch`、`release`）

## 背景

换字时旧字退场、新字进场，两帧的自然宽度不同，容器宽度会在退场帧塌到旧字宽度，尾部元素（卡片右边界等）跟着瞬间跳位。流式输出每次增量都会换字，每帧都跑一遍滚动动画就是连续闪。

## 决定

`live` 相同且新文本以旧文本开头时，认定是流式增量，原地更新那段文字，不滚动也不锁宽。其余换字用 `Element.animate` 把宽度从旧值滑到新值，退场期间把容器宽度钉在旧值，等最后一个离场元素走完再放回自然宽度。

## 后果

宽度锁定与释放必须成对：释放早了卡片弹回，漏了释放下个换字带着旧宽度走。流式分支是这段逻辑的前提，去掉后每个增量都会闪一次。
