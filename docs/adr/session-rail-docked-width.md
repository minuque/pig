# 摘要卡的常驻门槛

- 状态：已采纳
- 代码：`apps/web/src/features/session-rail/lib/layout.ts`（`RAIL_DOCKED_MIN`、`railModeOf`）

## 背景

摘要卡有两种形态：在对话右侧独占一列的常驻面板，和收进头部按钮的浮层。常驻要同时放下正文最小宽度、
卡片本身、拖拽间距与两侧留白，宽度不够就会挤扁正文。

## 决定

常驻门槛取 1012px = 正文 640 + 卡片 280 + 间距 12 + 两侧留白 32 + 余量 48；低于它收成浮层。
右侧面板在面板列里，不占正文宽度，不参与这个门槛。

## 后果

窄窗不挤压正文。改正文最小宽度、卡片宽度或间距时，要同步重算这个常量，否则门槛与实际布局对不上。
