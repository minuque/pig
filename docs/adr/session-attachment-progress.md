# 附件上传进度用插值模拟

- 状态：已采纳
- 代码：`apps/web/src/features/session/hooks/use-background-send.ts`（`stageBatch`）

## 背景

stage 是单请求接口，拿不到逐字节进度。等待期间进度环停在 0，看起来像卡住。

## 决定

每个文件 stage 开始时从 0 起，用随机插值每 50ms 爬到 85 的上限；真实 await 落定后直接顶到 100。
失败或中止时清掉整批进度，文件留在暂存里。

## 后果

进度环平滑且在真实完成时才满格。85 是插值上限，不是真实进度；改这个数只影响观感，
不要把它当成可读的完成度，也不要让插值越过 100。
